# 👻 GhostText — Teletext rises from the grave

A Kiroween 2026 (Resurrection) project: the 1970s TV Teletext service, reborn as a spooky, AI-powered 40x24 web news reader.

## Run
```
uv sync
uv run uvicorn app.main:app --reload
```
Open http://localhost:8000 and type a page number (try 100, 101, 400, 666).
